# Career Compass

An AI-powered tool that analyzes job descriptions and provides personalized career development advice.

## What it does

- Paste a job description → AI breaks down what the role really needs
- Compare against your resume → see where you match and where the gaps are
- Get actionable advice → specific projects, skills, and networking strategies to close the gaps
- Track your applications → deadlines, todos, and progress in one place

## Tech Stack

- **Frontend:** React
- **Backend:** Python + FastAPI
- **AI:** Claude API
- **Database:** SQLite
